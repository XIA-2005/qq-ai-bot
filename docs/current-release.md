**v0.9.6 界面修正：**「群聊历史导出」的群号输入框与导出范围下拉框共用标签和控件间距，双列时顶部和高度对齐；窄窗口仍改为单列。导出服务及真实 QQ 历史范围未因本次样式修改而改变；先前真实测试均为部分导出，不能称为完整历史。真实 Electron 窗口人工点击仍需另行核对。

## 功能与费用限制

- 回复仅在已保存、已启用的好友/群白名单内；自动登录并非自动放宽白名单。**保留默认群追问**：机器人在白名单群成功发言后 90 秒内，该群任何成员的未 @ 消息、近期群聊文字与机器人发言可能送模型判断；即使保持沉默也可能计费，积极度 0 也不关闭。旧版同意不覆盖此范围，升级后须在 Windows 主窗口重新确认；手机或 QQ 不能代确认。
- 桌面点击「保存配置」成功后**不重新扫码、不切换 QQ 账号**；即使此前手动暂停，也会解除暂停并请求自动开启。只有 QQ 已连接、API Key、已启用白名单、本版本群追问及费用知情确认齐备，且没有未完成请求时才会开启；条件不足则不发送并显示等待原因。保存被拒绝或取消不会改变运行状态；若要继续暂停，请在保存后再点击「暂停回复」。应用人设、清空对话和移动端设置各按原有独立规则执行。
- v0.9.2 起**默认启用费用护栏**：模型请求前落盘预留，每日全局 **¥2.00**、每位好友或每个群 **¥0.50**，聊天与该对象试聊共用对象额度；验证、人设、试聊也计入全局。已知用量以响应 Token 估算结算；未知、取消、中断保留风险预留；超出本软件额度或预算文件不可用时阻断新的付费模型请求。在桌面「用量统计 → 每日费用护栏」可确认后调整/关闭。
- **预算不是 DeepSeek 的实际账单硬上限**：真实单价、图片 Token、供应商计费及单次请求超预留可能让实际扣费高于软件估算。首次升级核对当日旧用量；历史不足以核对时当天安全阻断，可在核实风险后自行调整或次日恢复。暂停、余额查询、配对撤销等不调用付费模型的操作不受费用额度限制。
- 私有数据保存在本机 Electron userData（通常 `%APPDATA%\QQ AI Bot`），应用级预算日志只记日期、好友/群号码和估算金额，不存 API Key、设备 Token 或聊天正文。QQ/NapCat 自身仍可能保存本地会话及登录资料。

## 群上下文、情绪分类与加密备份（v0.9.5）

- 常规群聊回复的背景上下文取「最近 30 条」与「最近 24 小时」的较大集合，缓存最多 100 条；发给模型的 JSON 上下文最多 8,000 字符，优先保留新消息和被引用消息。截断时在模型提示和本机日志中说明，日志不记录聊天正文。持续参与和主动接话仍分别使用各自较短的判断窗口。
- **逐张主动看图默认关闭：**在「回复规则」另行勾选并确认后，已开启主动接话、同时允许视觉上传的白名单群，每张群友未 @ 的普通图片都可能单独上传 DeepSeek 并触发付费判断，即使不发言也可能计费。按用户选择，新模式**没有额外逐群图片时间间隔**；仍受常规发送任务冷却、全局每分钟限流与预算护栏，模型可能保持沉默。真正读取失败时不调用模型；点评最多一行、30 个 Unicode 字符。积极度为 0 仍关闭主动接话；其他档位的旧消息数／每小时发言限制不限制逐张图片判断。旧「主动接话群看图间隔」只约束未启用新权限的旧模式。导入备份会撤销新权限；上线前告知群成员并用测试群核对费用。
- **每次聊天先独立分析默认关闭：**在「回复规则」单独勾选并确认后，已获授权的好友、群 @、持续参与、90 秒追问、主动接话及逐张图片候选，会先用一次 DeepSeek 请求分析现有有限文字上下文（最多 256 输出 Token），再用第二次请求决定回复或沉默。即使最终保持沉默，也可能产生两次费用；真实聊天每分钟请求上限按**实际调用次数**计算，两次占两个名额，可能等待。图片原图不另行上传给分析请求，只随最终请求上传；语境笔记作为非权威数据仅用于当次最终请求，不发送 QQ、不写历史或日志。分析失败/超时/预算阻挡时尝试原来的回复请求，仍受白名单、图片许可、预算和限流约束；暂停、取消或主动候选过期不继续调用。配置历史恢复重新开启须确认；备份导入会关闭该开关。
- 新学到或旧版保存的群聊表情包默认「待人工分类」，**不因名字推断情绪**。在「回复规则」手动选择预设情绪后才会列入模型可选词并允许回发；未验证真实 QQ 发包效果。
- 全局夜间整理的旧开关不会自动向模型发送 QQ 号。仅同时开启全局夜间整理、在**该群**明确开启夜间整理，并单独确认该群的「QQ 号↔群名片映射」时，夜间请求才携带当天发言者的映射；普通回复不携带号码映射。撤销该群映射授权会清掉本地映射，导入备份后此授权全部撤销、须逐群重新确认。
- 「桌面设置」可手动创建/预览/导入 `.qqaibak`：每次手动输入至少 12 字符密码，以 scrypt 派生 AES-256-GCM 密钥。加密文件包含 API Key、人设及配置历史、预算/用量账本和 **QQ/NapCat 登录档案**，不包含 iPhone 配对设备令牌、日志或诊断。原机器已配对的手机设备**不会因导入自动撤销**，如需取消访问请在桌面单独撤销。
- 导出和导入前必须先暂停回复、停止本软件托管的 QQ 登录；备份限 **2 GB / 10,000 文件**，超限拒绝而不生成不完整包。导入先全文件认证和预览，确认后重新认证、写入应用数据目录中的临时待替换文件并提供回滚；异常中断残留会在下次启动清理，未完成回滚会阻止自动登录/回复。恢复成功后程序退出，重启后仍需重新确认自动回复、逐群 QQ 号披露、逐张主动看图与每次先分析权限，并检查账号与预算。**只用临时假资料做过离线测试，未用真实 QQ 登录档案做恢复演练。**

## 手机远程控制

当前客户端是**Safari/PWA**，不是已发布的 SwiftUI 原生 App。必须先由用户自行完成固定 HTTPS 子域、Cloudflare Named Tunnel 和 Windows 连接器配置；源站仅监听 `127.0.0.1:5188`，不向局域网开放。公开源码中的 `example.com` / `qqbot.example.com` 只是示例，**须替换为自己控制的域名并审查脚本后才能安装连接器**。旧 Quick Tunnel、固定 PIN、`/api/auth` 已弃用。在桌面「iPhone 安全远程控制」保存固定域名、创建 5 分钟一次性二维码，用 iPhone 系统相机扫码后 Safari 自动配对；可添加到主屏幕。具体安装边界见 [手机手册](mcp-ios-mobile-control.md) 与 [域名部署清单](remote-deployment.md)。**本轮自动化没有改动真实 DNS 或安装服务。**

设备使用独立、90 天有效的 HttpOnly/Secure Cookie（或受支持客户端的 Bearer Token）；磁盘只保存设备令牌哈希，可桌面逐台撤销、全部撤销，或设备自撤销。移动写操作使用同设备同 `Idempotency-Key` 的 **24 小时跨重启**收据；同进程可复用已缓存响应，重启后只返回最小恢复回执并应重新读取状态。重启前未确认完成的写操作返回 `409 IDEMPOTENCY_UNCERTAIN`，**不会盲目重做**；原 Key 与不同请求冲突时返回 `409 IDEMPOTENCY_CONFLICT`。设备自撤销后原令牌无权再查询，会直接返回 `401`。日志不持久化 Token、Key 原文、请求正文或桌面响应。

## 验证与人工边界

```bat
npm ci
npm run ci:offline
npm run test:browser
npm run preflight:runtime
npm run pack:win
```

`ci:offline` 使用假 NapCat/WS、假移动服务、假模型传输和本机临时目录，不登录真实 QQ、不调用 DeepSeek、不安装 Cloudflare。`test:browser` 用 Chromium 与假服务验证 PWA，并离线操作桌面对象设置表单；缺少 Chromium 时先运行 `node node_modules/playwright-core/cli.js install chromium`。`preflight:runtime` 和 `pack:win` 只在 Windows 已恢复并审查过 `vendor/napcat-runtime` 后运行；Git 不包含其大型第三方文件。`pack:win` / `dist:win` 写哈希清单、验证根启动器选中本版，再自动重跑测试并生成 `docs/releases/v0.9.6.md`；任何一步失败不算交付。只有核对实际进程指向新包后，才能称本轮修改已在桌面运行。

真实 QQ 登录和换号、付费 API 用量/账单、Cloudflare DNS/连接器安装、iPhone 蜂窝网络访问均须用户另行确认后手动验收；离线测试不代表这些外部系统已经可用。历史 P1 交付解释见 [v0.9.1](p1-repair-release-0.9.1.md)，早期方案/版本时间线均属归档。

## 实现与关键边界

### 逐对象配置

- `src/profiles.ts` 负责校验、继承解析、有效配置签名和主动接话权限变化判断。`Config.profiles` 以 `p:<账号>` / `g:<群号>` 为键，不添加新的白名单成员。
- 每行有号码、备注、启用状态和设置入口。未保存号码需先保存名单；备注普通编辑随全局保存，已保存对象的启停和弹窗设置立即生效。
- 人设、回复长度、记忆轮数、群模式分别继承或独立设置；群模式仅有继承、仅 @、允许主动接话。新增有效主动接话权限需要显式确认。
- 全局最大 Token 仍是独立长度的上限。仅 @ 模式保留已存在合并窗口内同作者补充消息的规则。
- `engine.updateConfig` 比较有效签名，只清理变化目标的任务和记忆；备注不触发清理。关闭对象立即取消排队与模型请求，迟到模型结果不发送，已经交给 QQ 的发送不能撤回。
- 群设置变化会清该群所有作者的记忆，不影响私聊或其他群。全局保存仍暂停本次回复，但独立设置不会被全局提示词覆盖。

### 独立试聊

- `src/preview.ts` 与真实 Engine、OneBot 发送路径分离。只允许选择已经保存的对象，可试聊停用对象但不会将其启用。
- 只在明确确认后调用模型；界面始终提示可能计费。试聊不读取真实聊天上下文，也不将试聊写入真实记忆。
- 内存保留最近 12 轮成功会话；模型上下文遵循目标记忆轮数。选择不同对象、有效配置变化、清空或退出会清理相应内容。
- 一个在途请求，独立每分钟额度不超过 min(全局 perMinute,10)。清空不重置额度；取消使用 AbortController 和 epoch 双重防迟到写入。
- 仅显示提供方实际返回的 Token 元数据；缺失或非法时显示未提供，不估算账单。试聊提示词、回复用 textContent 渲染。

### 桌面功能

- `src/desktop.ts` 单独保存关闭到托盘、掉线提醒偏好，不要求 API Key。
- 默认关闭窗口后收起托盘；托盘提供打开、暂停、恢复、彻底退出，恢复不能绕过首次回复许可。没有可用托盘时关闭窗口直接退出。
- Windows 开机启动默认关闭；只有打包生产配置并显式确认后才修改启动项，指向当前 EXE 与固定启动参数。隔离 user-data-dir 不允许修改启动项或弹出真实通知。
- 当前版本保存开机启动状态后，若移动程序目录或升级到新目录，应重新检查并保存启动设置。
- 已连接后掉线持续 5 秒提示，掉线通知间隔至少 120 秒；通知过的连接恢复后提示一次。首次未连接、短暂闪断、主动停止和退出不提醒。
- 验证中修复主动停止的中间状态问题：暂停产生的“仍连接”状态更新不会重新启用当前连接的掉线通知；观察到停止后的断开再恢复正常监控。
- 彻底退出取消请求、断开连接、销毁托盘并等待托管运行时停止。托盘收起不会停止运行时。

### 真实 EXE 隔离验收

临时 user-data-dir，不读取用户真实密钥、登录记忆或聊天资料，不启动 QQ 登录。
验证旧配置迁移、逐行名单增删粘贴、非法值、200 行上限、900/1180 宽度、调度参数保存、单目标设置、停用、群主动接话取消确认、全局提示词不覆盖独立人设、重启持久化。

试聊先验证计费确认取消和缺少 Key 拒绝；随后只在该临时进程内通过本机调试接口注入模型桩，并阻断 fetch，验证实际 IPC/UI 的回复、用量、取消迟到结果和清空。桩不写入应用源码、安装包或用户配置，没有真实模型调用。截图中的桩回复明确标注并非真实模型实测。

真实创建托盘；使用主进程 BrowserWindow.close() 模拟原生关闭事件，确认隐藏而非退出；启动同配置第二实例确认原窗口恢复且第二实例退出；明确退出后验证进程结束。恢复验证采用原生窗口 isVisible/isFocused 状态，不把 Windows 遮挡下的 document.visibilityState 当作原生窗口显示状态。早期使用 renderer window.close() 的调试方式已替换，不作为最终验收方法。

系统启动项和通知的权限、去抖、回滚及主动停止边界由 fake Electron / fake clock 单测验证；隔离 EXE 另验证启动项操作被拒绝。没有实际注册开机启动，没有弹真实系统通知，也没有进行 Windows 注销重登验证。

## 使用提示与未实测范围

每次启动自动回复和首次风险许可继续保留；手动暂停影响本次运行，彻底退出后再打开重新等待前置条件自动开启。保存全局设置仍暂停本次回复，单目标保存不暂停其他对象。

新版关闭按钮默认收起托盘；需要停止软件时选择“彻底退出”。开机启动必须用户自行确认开启。

本次没有真实 QQ 收发、付费模型效果/费用测试、真实掉线系统通知或开机登录实测。已有单元测试和隔离 EXE 验收不能替代这些真实环境检查。

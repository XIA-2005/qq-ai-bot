# 群聊持续参与（多人群聊互动）设计方案与实施计划

日期：2026-09-21

## 一、需求背景与核心目标

### 1. 业务痛点
在传统的 QQ 群聊交互中，机器人通常采用“必须逐条 @ 才会回复”的单次触发模式。这在群友间开展连续讨论时显得非常繁琐，严重割裂了对话的自然连贯性；而如果简单放开为“监听群内所有消息并每条必回”，又会导致机器人强行抢话、严重刷屏，并引发不必要的 API 费用暴增。

### 2. 核心目标
1. **单次唤醒，持续参与**：在群聊中通过一次明确的 @（或满足高置信度的主动接话条件）唤醒机器人后，机器人进入该群的“持续参与会话（Group Session）”。
2. **群级共享，多人群聊**：机器人服务的对象是“整个群聊场域”，而不是仅仅与唤醒它的人绑定私聊。其他群友无需再次 @，其发言也会被纳入讨论上下文，机器人能够自如地与不同群友穿插交流。
3. **智能决策，按需回应**：在会话持续期间，机器人不是机械地每句必回，而是结合上下文智能判断是否需要发言（如提问、求助、呼应、提供建议等）；对群友间的私人寒暄或无关闲聊保持安静。
4. **自然淡出，冷场结束**：若群内持续一段时间（如默认 10 分钟）无人继续交流，会话自动结束并重置，避免机器人长时间在后台盲目处于监听状态。

## 二、系统架构与技术设计

### 1. 核心模块与职责分工
- **`src/group-session.ts`（会话状态中枢）**：
  - 内存维护按群隔离的 `GroupSessions` 映射表，支持毫秒级时钟调度与冷场判断。
  - 维护滑动窗口上下文（最近 16 条发言，单条截断 400 字符）。
  - 动态成员代称映射（`Member Mapping`）：将真实 QQ 号转换为 `成员1`、`成员2`，实现上下文一致性并隔离敏感隐私。
- **`src/engine.ts`（消息调度引擎）**：
  - 消息前置过滤：过滤 @全体成员、忽略名单、纯图片或空内容。
  - 任务优先级仲裁：当出现明确的 @ 消息时，主动取消当前群正在排队但尚未执行的判断任务。
  - 连续发话抑制：若上一条刚刚由机器人发出，对随后的普通附和默认提高沉默门槛，防止自言自语或死循环。
- **`src/onebot.ts`（传输层适配）**：
  - 区分消息发送模式：明确 @ 的回复带 At 码；Session 持续期间的主动跟评作为纯文本直接广播群聊。
- **`src/usage-ledger.ts`（费用闭环）**：
  - 每次智能决策（即使最终判定沉默未发话）均产生的模型调用，统一归属计入对应群（`g:<group>`）的累计估算金额中。

### 2. Prompt 工程与决策协议设计
模型输入包含两部分：
1. **系统预设与边界指令**：明确告知处于多人交流场域，群成员用编号代称；强调“默认保持安静，只在明显需要你回应时才回复，坚决不抢话”。
2. **结构化输出协议**：
   - 不回应时输出：`{"reply": false}`
   - 决定回应时输出：`{"reply": true, "text": "回复内容..."}`

## 三、落地实施与迭代计划

### 阶段一：核心会话上下文与多发言人抽象
- [x] 设计按群隔离的 `GroupSessions` 内存管理模型。
- [x] 实现群友发言人代称自动编号（`成员1`、`成员2`...）与上下文队列。
- [x] 实现最近 N 条（默认 16 条）消息滑动窗口与单条字符截断机制。

### 阶段二：智能响应决策与防刷屏机制
- [x] 设计两阶段 JSON 决策指令（回应 / 沉默）。
- [x] 增加机器人自发话抑制逻辑（`lastFromBot` 静音约束）。
- [x] 实现明确 @ 抢占机制（撤销滞留的低优先级判断任务）。

### 阶段三：会话生命周期与冷场管理
- [x] 实现基于定时器的动态冷场退出机制（默认 10 分钟无新发言自动关闭）。
- [x] 联动外部中断：手动暂停、清空记忆、关闭软件时即刻销毁会话。

### 阶段四：UI 呈现与配置交互
- [x] 在白名单群设置中引入模式切换（`direct` 仅回复@ / `session` 持续参与 / `sessionAuto` 持续参与+主动加入）。
- [x] 提供冷场超时可配置项（1–120 分钟），保存时具备费用风险二次确认弹窗。
- [x] 运行状态区新增活跃房间卡片展示（群号、来源、成员数、条数、预计结束时间）。

### 阶段五：自动化测试与端到端验证
- [x] 单元测试：覆盖成员映射、滑动窗口修剪、冷场定时器触发、沉默判定。
- [x] 端到端验证：通过 CDP 模拟多人群聊发言序列与异常断网重连。

## 四、预期效果与价值
1. **更符合人类群聊直觉**：一次呼叫后，群内讨论自然展开，多位群友可无缝加入交流。
2. **克制智能，绝不扰民**：严格的沉默机制与冷场退出，保证机器人既“随叫随到”，又“不抢话不刷屏”。
3. **费用可控透明**：与已有的 v0.8.2 用量账本无缝贯通，群友聊天消耗一目了然。
